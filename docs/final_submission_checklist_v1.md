# Final Submission Checklist

Course: CO543/CO5430 Computer Vision  
Project: Waste Image Classification  
Group: G20  
Project ID: P04

## Submission Items

- Final report in IEEE format, around 6-8 pages.
- GitHub repository link.
- Final presentation slides.
- Recorded presentation/demo link or file.
- Individual contribution statement.

## Repository Check

- README explains the problem, dataset, model, results, and demo.
- Dataset location is clear: `data/raw/`.
- Dataset files are not committed.
- Model files are not committed.
- Final checkpoint path is clear: `models/mobilenet_v2_v1.pt`.
- Requirements are listed in `requirements.txt`.
- Main scripts are available inside `scripts/`.
- Web app is available inside `app/`.
- Result charts and examples are available inside `docs/`.

## Report Check

- Abstract
- Introduction and motivation
- Related work
- Dataset and preprocessing
- Methodology
- Baseline and improved/adapted methods
- Experiments
- Quantitative results
- Qualitative results
- Failure cases and analysis
- Limitations
- Conclusion
- References
- Individual contributions

## Presentation Check

- Problem and motivation
- Dataset
- Method and implementation
- Model comparison
- Final test results
- Qualitative results and failure cases
- Demo workflow
- Next steps and limitations

## Recording Check

- Start with project title and team.
- Explain the problem clearly.
- Show the GitHub repository briefly.
- Show the main results.
- Show the web app demo if possible.
- Keep the full recording around 7-10 minutes.
