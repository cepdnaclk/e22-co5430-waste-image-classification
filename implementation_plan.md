### Phase 6 Results Context

The Phase 6 comparison file shows both MobileNetV2 and EfficientNet-B0 at **8.3% accuracy / 0.024 macro F1**, which is near-random for 12 classes. The README explicitly notes: *"Validation scores above are from a tiny mock dataset run."* The Phase 6 class report shows only 2 images per class in the validation set.

This means Phase 6 was run with `--max-val-per-class 2` or similar tiny limits, producing unreliable metrics. The models were saved as `models/mobilenet_v2_v1.pt` and `models/efficientnet_b0_v1.pt` but those files are not present locally (gitignored).
